# Obsidian Git Sync Setup

## What This Repo Tracks
This vault repo tracks **documentation, notes, and planning only**.

Code repositories (RML-Soundscape, RML-SalesGym, etc.) are **ignored** here and have their own git repos.

## Setup Steps

### 1. Install Obsidian Git Plugin
1. Settings → Community plugins → Browse
2. Search "Obsidian Git"
3. Install & Enable

### 2. Configure Plugin (Recommended Settings)
Settings → Obsidian Git:
- **Auto backup**: `10` minutes (adjust to your preference)
- **Auto pull**: On startup
- **Commit message**: `vault backup: {{date}}`
- **Push on backup**: Yes (if you want auto-sync)

### 3. Create GitHub Repo (Optional but Recommended)
```bash
# On GitHub, create new repo: "rogue-media-lab-vault"
# Then link it:
git remote add origin git@github.com:YOUR_USERNAME/rogue-media-lab-vault.git
git branch -M main
git add .
git commit -m "Initial vault setup"
git push -u origin main
```

### 4. First Commit (Manual)
```bash
cd /home/masonroberts/Rogue-Media-Lab
git add .
git commit -m "Initial Obsidian vault setup with project structure"
```
